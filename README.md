# 🚗 Ford Car Price Prediction using Machine Learning

This project predicts the resale price of Ford cars using machine learning techniques.  
The model learns patterns from historical car data such as year, mileage, engine size, and transmission type.

---

## 📊 Project Overview

Accurately estimating car prices is important for buyers, sellers, and dealerships.  
In this project, I built a machine learning model to predict Ford car prices based on various features.

---

## 🧠 Machine Learning Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Encoding Categorical Variables
5. Feature Scaling
6. Model Training
7. Model Evaluation

---

## 📂 Dataset Features

The dataset contains information such as:

- model
- year
- transmission
- mileage
- fuelType
- engineSize
- mpg
- tax
- price (target variable)
